# Luna Guardian

Android project package for Luna Guardian v0.2.

The source archive is `LunaGuardian-android-v0.2.zip`. GitHub Actions unpacks it and builds the debug APK automatically.

Features in v0.2:
- OFFLINE / ASK / ONLINE network modes
- user-approved temporary network leases
- local encrypted knowledge vault
- localhost Ariana/Luna hub on 127.0.0.1:8766
- authenticated blackboard messaging
- prepared Audio Sense feature endpoint

The app does not modify Meta AI. Network control uses Android's user-approved VPN service and targets the configured Meta AI package.
